# Alibaba B2B Listing

Load `skill.json` as the runtime manifest.

## Workflow

1. Map the chosen category to the configured Alibaba Showroom slug.
2. Fetch the live public Showroom page and extract hot product titles, links, images, price bands, and MOQ clues.
3. Convert the live titles into sourcing-oriented keywords.
4. Merge those keywords into the Alibaba prompt template with the user inputs and uploaded reference images.
5. Keep the result trustworthy, specification-aware, and suitable for B2B landing/detail pages.

## Output Bias

- Favor clean industrial lighting and credible material detail.
- Surface MOQ, material, packaging, OEM/ODM, or size modules when infographic mode is selected.
- Avoid retail-only visual language and exaggerated consumer promo styling.
